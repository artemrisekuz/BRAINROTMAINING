# Telegram-бот Violet Vault

Бот — это отдельный чат с ботом Telegram: кейсы, баланс, дропы и продажа предметов через кнопки. Он использует `properties.json`, существующие веса выпадения и тот же файл состояния, что сайт.

## Подключить бота

1. Откройте Telegram и найдите официальный `@BotFather`.
2. Создайте бота командой `/newbot`, задайте имя и username. BotFather выдаст секретный токен.
3. Опубликуйте сайт на доступном из интернета домене с HTTPS. `localhost` и обычный HTTP в Telegram Mini App не откроются.
4. Скопируйте `.env.example` в `.env`. Впишите токен только в `TELEGRAM_BOT_TOKEN`, а опубликованный адрес сайта — в `TELEGRAM_WEBAPP_URL` (например, `https://my-site.example`). Не коммитьте `.env` и не отправляйте токен в чат.
5. В @BotFather укажите домен сайта командой `/setdomain`, если Telegram попросит настроить домен Web App.
6. Установите зависимости командой `npm install`.
7. Запустите одной командой сайт и бота: `npm start`. Сайт будет на локальном порту 3000, бот запустится polling-процессом, используя публичный `TELEGRAM_WEBAPP_URL`.
8. Откройте бота в Telegram и нажмите **Start**. Бот поприветствует и отправит inline-кнопку **🎮 ИГРАТЬ**; нажмите её, чтобы открыть сайт внутри Telegram с данными пользователя. В меню чата также появится постоянная кнопка **Играть**. Не запускайте Mini App через старую reply-клавиатуру: Telegram не передаёт оттуда initData.

Для разработки с перезапуском при изменениях: `npm run dev:bot`.
Для остановки и сайта, и бота нажмите Ctrl+C в терминале с `npm start`. Отдельно запустить только сайт можно через `npm run start:site`.

## Команды бота

- `/start` — главное меню
- `/cases` — список кейсов, цены и отображаемые шансы
- `/profile` — баланс и выпавшие предметы
- В профиле кнопка у каждого предмета продаёт его за цену из `properties.json`.

Telegram Bot API сам выдаёт профильный ID пользователя. Mini App отправляет `initData`, сервер проверяет подпись Telegram и привязывает сессию к тому же ID `TG<id>`, что использует бот. Телефон, пароль и код входа не запрашиваются.

Доступ к боту, игровым API и Mini App разрешён только Telegram ID `6987783335`. Другим пользователям бот отвечает «ВЫ НЕ АДМИН!», а Mini App не выдаёт игровую сессию.

## Важно

Токен хранится только локально в `.env`, который добавлен в `.gitignore`. Значение токена, ранее отправленное в чат, следует отозвать через @BotFather (`/revoke`) и вставить новый токен локально. Mini App не откроется по `localhost`: нужен развёрнутый публичный сайт с HTTPS. `npm start` поднимет сайт, но сообщит, что бот пропущен, пока не настроены оба значения в `.env`.
