# Изображения

Положите сюда изображения из `properties.js`.

Пример:

```text
images/
  starter-case.webp
  luckyblocks-case.webp
  legendary-case.webp
  noobini-pizzanini.webp
  taco-lucky-block.webp
  arcadragon.webp
  gingerbread-base.webp
```

Можно использовать `.webp`, `.png`, `.jpg` или `.svg` — главное, чтобы имя в поле `image` совпадало с файлом.
